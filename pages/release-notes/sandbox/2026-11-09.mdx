# Sandbox - November 9, 2026

Published: November 9, 2026.
Product line: Sandbox.
Public URL: [sandbox.tangle.tools](https://sandbox.tangle.tools).

## Customer Impact

No migration is required.
Links to the old docs.tangle.tools addresses redirect to the matching pages under [/sandbox](/sandbox/overview).

## What Changed

- The Sandbox documentation is organized as one guide at [docs.tangle.tools/sandbox](/sandbox/overview), with TypeScript, Python and CLI examples on each task page.
- New pages: [How sandboxes work](/sandbox/concepts), [Limits and timeouts](/sandbox/limits), [Error codes](/sandbox/errors), [Troubleshooting](/sandbox/troubleshooting), and guides to move from [E2B](/sandbox/migrate-e2b), [Daytona](/sandbox/migrate-daytona) and [Modal](/sandbox/migrate-modal).
- The [REST API reference](/sandbox/api-reference) lists every route, and the OpenAPI document is published at [/sandbox-openapi.json](/sandbox-openapi.json).
- The Python SDK installs with `pip install tangle-sandbox`; see the [Python SDK](/sandbox/sdk-python).
