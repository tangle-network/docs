# Tangle builds infrastructure for AI agents

Tangle provides five infrastructure layers: Sandbox, Runtime, Router, Integrations, and observability through Intelligence.
Evaluation belongs inside each layer and each product.
Tangle's product and research labs use the same infrastructure.

Developers can start with the live [Sandbox](/sandbox) and [Router](/gateway) services.
The [architecture page](/vision/architecture) explains the five layers and the separate protocol path for operator-hosted services.

## The five layers

- **[Sandbox](/sandbox):** isolated computers for agent work.
- **[Runtime](/infrastructure/introduction):** sessions and execution control for agents in those sandboxes.
- **[Router](/gateway):** model requests across supported providers and explicit operator routes.
- **Integrations:** connections to supported tools, data, and external events.
- **[Intelligence](/intelligence):** traces and comparisons for inspecting runs and measuring changes.

Evaluation uses evidence from these layers to test behavior and changes.
It is part of the infrastructure and its products, rather than a separate infrastructure layer.

## Products built on the infrastructure

The product lab uses these layers for Agent Builder, Braid, vertical apps, and hosted assistants.
The research lab uses them for discovery and the software factory.
The hosted assistants are the first packaged use case, starting with hospitality.
Agent Builder is expected to provide the hosted creation and approved-channel setup path.
The first completed text reply and request-to-resolution flow have not yet been verified.
The hosted assistant remains a preview.

## Deployment boundaries

Managed Sandbox and Router services are live today.
The [protocol](/network/overview) supports a separate path for operator-hosted Blueprint services and on-chain settlement.
The company plans a hostable on-prem option for infrastructure; these docs do not present an available installation path.
