# Infrastructure Architecture

Tangle builds five infrastructure layers for AI agents.
Products and research systems use the same layers.
Evaluation belongs inside each layer and product.

| Layer                        | Responsibility                                                                     | Start here                                                         |
| ---------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| Sandbox                      | Give an agent an isolated computer with files, a shell, and browser access.        | [Sandbox](/sandbox)                                                |
| Runtime                      | Control agent sessions, execution, and streaming events in sandboxes.              | [Runtime](/infrastructure/introduction)                            |
| Router                       | Send model requests to supported providers or explicitly selected operator routes. | [Router](/gateway)                                                 |
| Integrations                 | Connect agents to supported tools, data, and external events.                      | [Protocol job triggers](/developers/blueprint-runner/job-triggers) |
| Observability (Intelligence) | Collect traces so teams can inspect runs and compare changes.                      | [Intelligence](/intelligence)                                      |

An application can start a session through Runtime in a Sandbox.
The agent can call models through Router and use integrations permitted by that application.
Intelligence can record the run's trace.
Evaluation can check execution, routing, tool use, and the resulting product behavior against the evidence each surface produces.

## Products and research

The product lab builds Agent Builder, Braid, vertical apps, and hosted assistants on this infrastructure.
Hosted assistants are the first packaged use case and remain a preview.
The first completed text reply and request-to-resolution flow have not yet been verified.
The research lab uses the same infrastructure for discovery and the software factory.

## Managed and operator paths

The managed [Sandbox](/sandbox) and [Router](/gateway) services are live.
Standard Router requests use supported provider APIs.
An operator-pinned or SpendAuth request can use a registered operator route.
The [protocol](/network/overview) separately supports operator-hosted Blueprint services and on-chain settlement.
That path requires a registered service instance and a reachable operator endpoint.
Access to a managed service does not establish an operator service or an on-prem installation.

Tangle plans to offer infrastructure that can be hosted on-prem.
These docs do not provide an on-prem installation path today.
