# Connect PriceLabs

PriceLabs recommends the right nightly price for each of your listings. Once
it's connected, your agent can answer "what should we charge this weekend?"
with **today's actual recommendation** instead of a guess — and your manager
sees the same numbers in the workspace that PriceLabs shows in its dashboard.

You connect it by creating one API key inside PriceLabs and pasting it into
your workspace.

**Time:** about 3 minutes. **You need:** a PriceLabs account login.

## Step 1 — Create an API key in PriceLabs

1. Sign in to PriceLabs.
2. Open your account settings and find the **API key** page (under
   Integrations or Account).
3. Create a key and copy it. PriceLabs may call it a **Customer API key** —
   that's the one.

## Step 2 — Add the key to your workspace

1. Open your Tangle workspace (for example
   [hospitality.tangle.tools](https://hospitality.tangle.tools)) and go to
   **Setup → Connections**.
2. Choose **PriceLabs** and paste the key.
3. Your workspace asks you to map each listing you want to use — for each
   one, two short fields:
   - **Listing ID** — the listing's ID in PriceLabs.
   - **PMS** — the property system the listing belongs to, for example
     `cloudbeds`.
4. Add up to 20 listings, then confirm with **Use for business data**.

## Step 3 — Confirm it's working

Ask your agent: **"What's the recommended price for the garden villa this
weekend?"** If it quotes a real PriceLabs number for a listing you mapped,
you're connected.

## Good to know

- PriceLabs data is **advisory**: it informs answers and suggestions, it
  never changes prices anywhere. Changing prices stays a human action in
  PriceLabs.
- The key is stored encrypted in Tangle's integration vault, never displayed
  again, and works only for this workspace.
- To cut the connection, remove PriceLabs in **Setup → Connections** or
  delete the key in PriceLabs.
