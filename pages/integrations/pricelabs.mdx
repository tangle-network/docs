# Connect PriceLabs

PriceLabs recommends a nightly price for each of your listings. A configured
connection lets your agent answer pricing questions using those
recommendations. Tangle's connector reads this data; it does not change your
listing prices.

## Before you start

**Current Hospitality setup limitation:** the initial PriceLabs connection
requires each listing's ID and PMS. The current connect dialog only collects
the API key, so it cannot finish a new PriceLabs connection. The later
**Use for business data** form cannot repair a failed initial connection.
Ask Tangle to confirm that the listing-aware setup is available before
enabling paid API access solely for this integration.

**Cost:** PriceLabs' Customer API costs **$1 per listing per month, plus tax**
for every listing that syncs during the billing month. Review the current
[PriceLabs API enablement terms](https://developers.pricelabs.co/customer-api/api-reference/enable-the-api)
before enabling it. Only the account owner can enable or revoke a team
member's API access in **Team Settings**; a sub-user needs that permission.

## Step 1 — Enable the Customer API in PriceLabs

When you have confirmed a supported setup path and accepted PriceLabs' costs:

1. Sign in and open **Account Settings → API Details**.
2. Choose **Enable**, then **I Need API Access**.
3. Type **API** and choose **Continue** to complete enablement.
4. Copy the Customer API key shown in **API Details** and keep it private.

The key inherits its user's listing permissions. Confirm that this user can
access the listings you intend to connect; Tangle's configuration does not
reduce the key's provider-side permissions.

## Step 2 — Register an existing connection for business data

These steps apply only if an active PriceLabs connection already exists for
your workspace. They do not bypass the new-connection limitation above.

1. Open your [Hospitality workspace](https://hospitality.tangle.tools) as an
   owner or manager, then open **Integrations → Business integrations**.
2. On the active PriceLabs connection, choose **Use for business data**.
3. Map each listing with its exact **Listing ID** and **PMS** value from
   PriceLabs, for example `cloudbeds` where that is the listing's PMS.
4. Add up to 20 listings and confirm with **Use for business data**.

## Step 3 — Confirm it's working

Once both connection and registration have succeeded, ask your agent:
**"What's the recommended price for the garden villa this weekend?"**
Compare the listing, dates, and price with PriceLabs. If data is unavailable,
check the listing mapping and provider permissions rather than treating a
connected row as proof of a completed sync.

## Good to know

- PriceLabs data is **advisory**: changing prices stays a human action in
  PriceLabs.
- Tangle stores the key encrypted and does not display it again in the workspace.
- Disconnect in **Integrations** to stop using the connection. Revoke the key
  in PriceLabs to invalidate the credential. Disconnecting Tangle does not
  itself cancel PriceLabs' paid API access; manage that in PriceLabs.
