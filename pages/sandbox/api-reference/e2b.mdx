# E2B-compatible routes

These routes accept E2B's REST request and response shapes. Send your Tangle API key in `X-API-Key`, as E2B's API expects, or as a bearer token.

Every route is on `https://sandbox.tangle.tools` and takes your account API key as `Authorization: Bearer <key>` unless it says otherwise. Errors use the shape in [Error codes](/sandbox/errors).
This page is generated from the [OpenAPI document](/sandbox-openapi.json), which also has every response schema.

## E2B compatibility

| Route | Does |
|---|---|
| `POST /e2b/sandboxes` | Create a sandbox |
| `GET /e2b/sandboxes` | List sandboxes |
| `GET /e2b/sandboxes/{sandboxID}` | Get a sandbox |
| `DELETE /e2b/sandboxes/{sandboxID}` | Kill a sandbox |
| `GET /e2b/sandboxes/{sandboxID}/files` | Read a file |
| `POST /e2b/sandboxes/{sandboxID}/files` | Write a file |
| `DELETE /e2b/sandboxes/{sandboxID}/files` | Delete a file |
| `GET /e2b/sandboxes/{sandboxID}/files/list` | List a directory |
| `POST /e2b/sandboxes/{sandboxID}/processes` | Run a command |
| `GET /e2b/sandboxes/{sandboxID}/processes/{pid}` | Get a process |
| `DELETE /e2b/sandboxes/{sandboxID}/processes/{pid}` | Kill a process |
| `POST /e2b/sandboxes/{sandboxID}/timeout` | Set a sandbox timeout |
| `GET /e2b/templates` | List templates |

### Create a sandbox

`POST /e2b/sandboxes`

E2B's `POST /sandboxes`. `templateID` is an id from `GET /e2b/templates`; `timeout` is the lifetime in seconds (default 15). Answers once the sandbox runs.

Authentication: an API key in `X-API-Key` or an API key as a bearer token.

Request body (`application/json`):

| Field | Type | Required | Description |
|---|---|---|---|
| `templateID` | string | Yes |  |
| `metadata` | object | No |  |
| `envVars` | object | No |  |
| `timeout` | number | No |  |
| `secure` | boolean | No |  |
| `allow_internet_access` | boolean | No |  |
| `autoPause` | boolean | No |  |
| `autoResume` | object | No |  |

| Status | Meaning |
|---|---|
| 201 | Running sandbox |
| 400 | Invalid request |
| 401 | Missing or invalid API key |
| default | Any other Sandbox API refusal, with its status and Retry-After header |
