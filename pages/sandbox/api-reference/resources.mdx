# Fleets, templates, secrets and teams routes

Manage fleets of sandboxes and the resources sandboxes start from or share: templates, images, instances, secrets, SSH keys, startup scripts, lines and teams.

Every route is on `https://sandbox.tangle.tools` and takes your account API key as `Authorization: Bearer <key>` unless it says otherwise. Errors use the shape in [Error codes](/sandbox/errors).
This page is generated from the [OpenAPI document](/sandbox-openapi.json), which also has every response schema.

### Stream a command dispatch to fleet machines

`POST /v1/fleets/{fleetId}/dispatch/stream`

Takes the same body as POST /v1/fleets/\{fleetId\}/dispatch and answers as server-sent events while the machines run. Each machine emits fleet.dispatch.branch.started and fleet.dispatch.branch.finished. The stream ends with fleet.dispatch.finished or fleet.dispatch.error. A failure before the stream starts is a JSON error instead. A dropped connection cancels the machines that have not started.

| Parameter | In | Required | Type | Description |
|---|---|---|---|---|
| `fleetId` | path | Yes | string |  |

Request body (`application/json`): one of 2 shapes; see the [OpenAPI document](/sandbox-openapi.json).

| Status | Meaning |
|---|---|
| 200 | Server-sent events (text/event-stream). Each frame has an event name and a JSON data field, modeled by the schema. |
| 400 | Invalid fleet ID or dispatch body (VALIDATION_ERROR) |
| 402 | The account that pays for the fleet has recorded debt (INSUFFICIENT_BALANCE) |
| 403 | The fleet token is not scoped to this fleet or lacks the exec or prompt action, or the backend's profile secret isolation is unavailable (FORBIDDEN, PROFILE_SECRET_ISOLATION_UNAVAILABLE) |
| 404 | Fleet not found (NOT_FOUND) |
| 409 | A dispatch with this dispatchId is already active (CONFLICT) |
| 429 | The paying account's balance is below the admission floor (QUOTA_EXCEEDED) |
| 503 | A selected machine could not be asked to prove secret isolation; retry after Retry-After (PROFILE_SECRET_ISOLATION_UNAVAILABLE) |

### Check fleet machines against the shared workspace mount

`POST /v1/fleets/{fleetId}/workspace/reconcile`

Compares each machine's recorded workspace mount path with the fleet's shared workspace mount path. It reads recorded state, contacts no machine and changes nothing. A fleet with no shared workspace mount path reports every machine as mounted. A fleet token needs the read action.

| Parameter | In | Required | Type | Description |
|---|---|---|---|---|
| `fleetId` | path | Yes | string |  |

| Status | Meaning |
|---|---|
| 200 | Mount check |
| 400 | Invalid fleet ID (VALIDATION_ERROR) |
| 403 | The fleet token is not scoped to this fleet or lacks the action (FORBIDDEN), or the credential is restricted to its sandbox |
| 404 | Fleet not found (NOT_FOUND) |
