# API reference

The sandbox lifecycle API is documented as an OpenAPI specification, served live from the product.

**Browse the interactive reference:** [sandbox.tangle.tools/docs/api-reference](https://sandbox.tangle.tools/docs/api-reference)

The interactive viewer includes:
- Every endpoint with parameters, request/response schemas, and examples
- Search across all operations
- Authentication requirements per route

## Quick reference

The base URL is `https://sandbox.tangle.tools`.

All requests need an API key:

```bash
Authorization: Bearer <tangle-api-key>
```

Create a key at [id.tangle.tools/app/keys](https://id.tangle.tools/app/keys).
