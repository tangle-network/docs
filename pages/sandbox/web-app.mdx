# Use the dashboard

The dashboard at [sandbox.tangle.tools/dashboard](https://sandbox.tangle.tools/dashboard) shows the same sandboxes as the SDKs, the CLI and the API.
Sign in with your Tangle account to create sandboxes, work in them, and manage templates, secrets, teams and billing.

## Sandboxes

The first page after sign-in lists your sandboxes with their status. Switch between your personal sandboxes and a team's from the workspace selector.

A sandbox's status is one of `pending`, `provisioning`, `running`, `stopped`, `failed`, `expired` or `deleted`; [How sandboxes work](/sandbox/concepts#sandbox-states) explains each.

Open a sandbox to work in it. The sandbox page has these tabs:

| Tab | What it shows |
|---|---|
| Overview | Uptime, coding-agent sessions, exposed ports, snapshots, secrets, and the sandbox's id and SSH command |
| Console | A terminal in the sandbox |
| AI Workspace | A chat with the sandbox's coding agent, beside its files |
| Desktop | The sandbox's remote screen, when the sandbox was created with a desktop |
| Metrics | Live CPU, memory and disk use, and coding-agent latency |
| Settings | Environment variables, processes, ports, the egress policy and the coding agent's settings |
| Snapshots | Saved copies of the sandbox's files |
| Logs | The sandbox's logs |

## Create a sandbox

**New sandbox** opens the create form at [sandbox.tangle.tools/dashboard/new](https://sandbox.tangle.tools/dashboard/new).

| Setting | Choices |
|---|---|
| Image | **Standard**, which includes the coding-agent tools, or **Custom image** with an image reference such as `ubuntu:24.04`. |
| Bare container | With a custom image, run commands and the lifecycle without the managed runtime or a coding agent. |
| Workspace size | A preset size, or exact CPU, memory and storage. A compute estimate updates as you change it. |
| Desktop | **Enable remote desktop** gives the sandbox a remote screen and computer controls. It needs an image that supports the coding agent. |
| Share with | Yourself or one of your teams. |
| Egress policy | Which hosts the sandbox can reach, with its allowed domains. See [Network access](/sandbox/egress). |
| Environment variables | Variables the sandbox starts with. |
| SSH access | The SSH key that can open a shell in the sandbox. See [Shells and terminals](/sandbox/terminals). |

To give a sandbox your stored secrets, add them to a startup script or pass `secrets` when you create it from an SDK or the CLI. See [Secrets](/sandbox/secrets).

## Templates

[Templates](https://sandbox.tangle.tools/dashboard/templates) has a **Public** tab and an **Owned** tab for the templates you saved.
Creating a sandbox from a template starts it from the template's snapshot and environment variables; anything you set on the create wins.
The public gallery is also at [sandbox.tangle.tools/templates](https://sandbox.tangle.tools/templates). See [Templates and images](/sandbox/templates-gallery).

## Secrets

[Secrets](https://sandbox.tangle.tools/dashboard/secrets) stores encrypted values for your account. Create, update and delete them here; a sandbox gets a secret only when a create or a startup script names it.
Team secrets are managed on the team's page. See [Secrets](/sandbox/secrets).

## Startup scripts

[Startup scripts](https://sandbox.tangle.tools/dashboard/startup-scripts) run when a sandbox with a coding agent starts. Use them to install tools, clone repositories or write configuration. See [Startup scripts](/sandbox/startup-scripts).

## Workflows

[Workflows](https://sandbox.tangle.tools/dashboard/workflows) lists your workflows and their schedules. **Create workflow** opens an assistant that writes one with you. See [Workflows](/sandbox/workflows).

## GPUs

When the GPU market is available, [GPUs](https://sandbox.tangle.tools/dashboard/gpus) lists GPU classes and signed price quotes.
Cloud GPUs attach to a sandbox through the SDK and CLI; see [GPU leases](/sandbox/gpu-leases).

## Teams

[Teams](https://sandbox.tangle.tools/dashboard/team) lists your teams. A team's page shows its members and roles, open invitations, shared sandboxes, team secrets and the team's egress policy.
Invite people by email or by copying an invitation link. Roles are Owner, Admin, Member and Viewer. See [Teams](/sandbox/teams).

## Billing

[Billing](https://sandbox.tangle.tools/dashboard/billing) shows:

- **Credit balance**, with your lifetime spend.
- **Account activity**: sandboxes created and messages today.
- Your plan, this month's egress and the current resource rates.

Change plan at [id.tangle.tools/app/plans](https://id.tangle.tools/app/plans) and add credit at [id.tangle.tools/app/billing](https://id.tangle.tools/app/billing).
Prices are on the [pricing page](https://sandbox.tangle.tools/pricing). See [Pricing and spend](/sandbox/cost).

## Settings

| Section | What it holds |
|---|---|
| [Account](https://sandbox.tangle.tools/dashboard/settings) | Your photo, name, email and plan; a link to your API keys at [id.tangle.tools/app/keys](https://id.tangle.tools/app/keys); and account deletion, which removes your API keys, sandboxes and usage history. |
| [Security](https://sandbox.tangle.tools/dashboard/settings/security) | Two-factor authentication with an authenticator app, and the SSH public keys you use to reach sandboxes. |
| [Notifications](https://sandbox.tangle.tools/dashboard/settings/notifications) | Whether Tangle emails you security alerts and product updates. |
