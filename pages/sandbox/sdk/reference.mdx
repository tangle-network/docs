## Git and tools

`box.git` provides `status()`, `diff()`, `log()`, `commit()`, `branches()`, `checkout()`, `pull()`, and `push()`.
Use the sandbox's configured Git credentials for private repositories.
Review changes before committing or pushing them.

`box.tools` lists installed tools and manages tool installation.
`box.backend` exposes the active backend's configuration, models, and supported provider operations.
Provider-specific operations can return `NOT_SUPPORTED`; use `client.listBackends()` to inspect advertised capabilities.

## Human decisions

Read outstanding requests with `session.interactions()` and keep their exact IDs.
Respond with `answer()`, `respondToPermission()`, or `respondToInteraction()` for the matching request.
An interrupted or waiting execution has not completed successfully.

`approvePlan()` and `rejectPlan()` can enqueue a follow-up turn.
Read that turn's admission and result rather than sending the same prompt again.
Use `interrupt()` or `cancelRun()` to stop work, and `delete()` to remove a session.

## Messaging and collaboration

`client.lines` manages messaging addresses connected through Tangle Hub.
`box.lines` attaches a line to a sandbox so incoming messages reach its agent.
Line creation and delivery require the corresponding Hub connection.

`CollaborationClient` and `CollaborationFileBridge` connect shared document changes with sandbox files.
Get the transport and access grant from `box.collaborate()` after checking the viewer's access.
Use `refreshCollaborationToken()` to renew it.
