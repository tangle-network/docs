# Traces and analysis

Inspect the result and tool calls from an agent run, or review the sandbox's runtime and usage.
Use [Tangle Intelligence](/intelligence) to investigate recorded agent activity across runs.

Set `TANGLE_API_KEY` and `TANGLE_SANDBOX_ID` to an existing sandbox.
Install the [TypeScript SDK](/sandbox/sdk/typescript), or `pip install httpx` for Python.
These examples leave the sandbox available for further inspection.

Use a running sandbox for this example.
The agent checks installed tools and saves its actual result to `agent-result.json` on your computer.

For live output and reconnecting to a specific execution, see [agents and sessions](/sandbox/sdk/agents-sessions).

## Save runtime timings

`box.trace()` exports the sandbox's observed lifecycle, runtime, and usage snapshots.
Use agent results and session events for the conversation and tool-call history.

The reported phases can overlap; their durations do not describe a sequence of agent steps.
