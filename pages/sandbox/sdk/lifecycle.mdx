# Sandbox lifecycle

Create a sandbox for a job, reuse it while work continues, and delete it when you finish.

`stop()` keeps the workspace for later use.
`resume()` starts it again; wait for `running` before sending work.
`delete()` releases the sandbox.

`maxLifetimeSeconds` limits each running interval on deployments that support suspension.
It suspends the sandbox rather than deleting its workspace.
Delete unneeded sandboxes explicitly, including sandboxes left behind by a failed script.

## HTTP endpoints

Python and other HTTP clients use the same API key.
See the [Python quickstart](/sandbox/sdk/python) for complete request setup and startup polling.

| Method   | Endpoint                    | Action                  |
| -------- | --------------------------- | ----------------------- |
| `POST`   | `/v1/sandboxes`             | Create a sandbox.       |
| `GET`    | `/v1/sandboxes`             | List sandboxes.         |
| `GET`    | `/v1/sandboxes/{id}`        | Read its current state. |
| `POST`   | `/v1/sandboxes/{id}/stop`   | Stop the sandbox.       |
| `POST`   | `/v1/sandboxes/{id}/resume` | Resume it.              |
| `DELETE` | `/v1/sandboxes/{id}`        | Delete it.              |
