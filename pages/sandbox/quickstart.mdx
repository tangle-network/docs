# Quickstart

Create an isolated machine, run a shell command in it, then hand it to a coding agent, all from a few lines of TypeScript.

## 1. Install the SDK

<CodeDisplay
  language="bash"
  code={"npm install @tangle-network/sandbox\nnpm install --save-dev tsx"}
/>

## 2. Get an API key

Create an `sk-tan-` key from [Authentication](/platform/authentication) and export it:

<CodeDisplay
  language="bash"
  code={"read -rsp \"Tangle API key: \" TANGLE_API_KEY\nprintf \"\\n\"\nexport TANGLE_API_KEY"}
/>

One key authenticates every Tangle product. Pass it to the client as `apiKey`; the SDK does not read env vars for you.

## 3. Check your credit and the service

Free accounts start with no included credit.
Add prepaid credit or select a plan with included credit at [id.tangle.tools](https://id.tangle.tools) before creating a sandbox.
Agent model usage also draws from your balance.
On the Free plan, sandboxes pause when the balance reaches zero.

Check your key and available credit without provisioning a machine:

<CodeDisplay
  language="bash"
  code={"curl -fsS https://id.tangle.tools/v1/billing/balance \\\n  -H \"Authorization: Bearer ${TANGLE_API_KEY:?Set TANGLE_API_KEY}\""}
/>

The response's `data.balance` is your available credit in US dollars.
You can also check the service and available templates without creating a sandbox:

<CodeDisplay
  language="bash"
  code={"curl -fsS https://sandbox.tangle.tools/health\ncurl -fsS https://sandbox.tangle.tools/v1/public-templates"}
/>

Each TypeScript block below is a separate program for Node.js 22 or later.
Run it in a project with the SDK installed and `TANGLE_API_KEY` exported.
Save either block as `example.ts` and run it with `npx tsx example.ts`.
Both examples release their machine after completion.

## 4. Create a sandbox and run a command

<CodeDisplay
  language="typescript"
  code={"import { Sandbox } from \"@tangle-network/sandbox\";\n\nconst apiKey = process.env.TANGLE_API_KEY;\nif (!apiKey) throw new Error(\"Set TANGLE_API_KEY\");\n\nconst client = new Sandbox({\n  apiKey,\n  baseUrl: process.env.SANDBOX_BASE_URL ?? \"https://sandbox.tangle.tools\",\n});\n\nconst box = await client.create({ environment: \"universal\", name: \"agent-smoke\" });\n\ntry {\n  const result = await box.exec(\"node --version && npm --version\");\n  console.log(result.stdout);\n} finally {\n  await box.delete();\n}"}
/>

`create` returns a live machine; `delete` releases it. You never provision infrastructure yourself.

## 5. Run a coding agent

Choose the initial coding harness with `backend.type`.
Sessions can select different [supported harnesses](/infrastructure/harnesses) in the same sandbox. `opencode` (OpenCode) is the default and needs no separate model-provider key. `claude-code` (Claude Code) runs on Tangle Router by default with no separate model-provider key. To bring your own Anthropic credential, pass `backend: { type: 'claude-code', model: { apiKey: process.env.ANTHROPIC_API_KEY } }`. See [supported harnesses](/infrastructure/harnesses) for the full list.

<CodeDisplay
  language="typescript"
  code={"import { Sandbox } from \"@tangle-network/sandbox\";\n\nconst apiKey = process.env.TANGLE_API_KEY;\nif (!apiKey) throw new Error(\"Set TANGLE_API_KEY\");\n\nconst client = new Sandbox({\n  apiKey,\n  baseUrl: process.env.SANDBOX_BASE_URL ?? \"https://sandbox.tangle.tools\",\n});\n\nconst box = await client.create({\n  environment: \"universal\",\n  backend: { type: \"opencode\" }, // Also supports Claude Code, Codex, and other supported harnesses.\n});\n\ntry {\n  const result = await box.prompt(\"List the files in this project and summarize what it does\");\n  console.log(result);\n} finally {\n  await box.delete();\n}"}
/>

For durable runs, use `box.dispatchPrompt(message, { sessionId, turnId })` and reconnect with `box.session(sessionId)`.
Store both IDs before dispatching and reuse them for retries of the same turn.
Completed retries are deduplicated while their results remain cached.
A session ID alone does not deduplicate completed retries.
See [durable sessions in the SDK reference](/sandbox/sdk-reference).
