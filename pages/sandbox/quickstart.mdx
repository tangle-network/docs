# Quickstart

Create a sandbox, run a command, and delete it when the work finishes.

## Get an API key

Create a key at [id.tangle.tools](https://id.tangle.tools) and add credit to your account.
Set `TANGLE_API_KEY` in your environment.
Keep this key on your server.
See [Authentication](/platform/authentication) for key setup.

TypeScript and JavaScript use the Sandbox SDK.
Python uses the HTTP API through HTTPX.

## Run a command

Save TypeScript as `example.ts` and run `npx tsx example.ts` with Node.js 22 or later.
For JavaScript, use `example.mjs` and `node example.mjs`.
For Python, use `example.py` and `python example.py`.
