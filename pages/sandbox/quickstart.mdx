# Quickstart

Create a sandbox, run a command, and delete it when the work finishes.

## Get an API key

Create a key at [id.tangle.tools](https://id.tangle.tools) and add credit to your account.
Set `TANGLE_API_KEY` in your environment.
Keep this key on your server.
See [Authentication](/platform/authentication) for key setup.
