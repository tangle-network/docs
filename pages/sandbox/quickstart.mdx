# Quickstart: run your first sandbox

Create an API key, start a sandbox, run a command in it, give a coding agent a task, and delete the sandbox.
Every step has a TypeScript, Python and CLI tab.

## Get an API key

Create a key at [id.tangle.tools/app/keys](https://id.tangle.tools/app/keys). Keys start with `sk-tan-`.

```bash
export TANGLE_API_KEY="sk-tan-..."
```

The key can create, run and delete every sandbox on your account. Keep it on a server, in a CI secret or in the CLI's keychain.
Browser code gets a short-lived token instead; see [API keys and tokens](/sandbox/authentication).

## Install

<Tabs items={["TypeScript", "Python", "CLI"]} storageKey="sandbox-lang">
<Tabs.Tab>

```bash
npm install @tangle-network/sandbox tsx
```

Save each program with the `.mts` extension and run it with `npx tsx <file>.mts`.
Top-level `await` needs a module, and a `.ts` file in a new npm project compiles as CommonJS.

</Tabs.Tab>
<Tabs.Tab>

The package is [`tangle-sandbox` on PyPI](https://pypi.org/project/tangle-sandbox/) and needs Python 3.10 or newer.

```bash
pip install tangle-sandbox
```

</Tabs.Tab>
<Tabs.Tab>

The installer brings its own Node.js runtime, so it needs no Node, npm or sudo, on macOS or Linux.

```bash
curl -fsSL https://sandbox.tangle.tools/install.sh | sh
export PATH="$HOME/.local/share/tangle-cli/bin:$PATH"
tangle auth login --api-key "$TANGLE_API_KEY"
```

The installer adds `tangle` to your shell profile; the `export` puts it on this terminal's PATH.
`tangle auth login --api-key` checks the key and saves it in the OS keychain, or in `~/.tangle/credentials.json` (mode 0600) on a machine without one, so a new terminal needs no export.
Without `--api-key`, `tangle auth login` signs in through your browser; `--no-browser` prints a device code instead.

With Node.js 22.19 or newer you can install the same CLI with `npm install -g @tangle-network/sandbox-cli`. Never run bare `npx tangle`: that npm name belongs to an unrelated package.

</Tabs.Tab>
</Tabs>

## Create a sandbox and run a command

<Tabs items={["TypeScript", "Python", "CLI"]} storageKey="sandbox-lang">
<Tabs.Tab>

```ts filename="run-code.mts"
import { Sandbox } from "@tangle-network/sandbox";

const client = new Sandbox({
  apiKey: process.env.TANGLE_API_KEY!,
  baseUrl: "https://sandbox.tangle.tools",
});

const box = await client.create();
try {
  const result = await box.exec("python3 -c 'print(sum(range(1_000_000)))'");
  console.log(result.exitCode, result.stdout);
} finally {
  await box.delete();
}
```

```bash
npx tsx run-code.mts
```

```text
0 499999500000
```

`client.create()` returns once the sandbox is running. `exec` does not throw on a non-zero exit, so read `exitCode`.

</Tabs.Tab>
<Tabs.Tab>

```python filename="run_code.py"
import os

from tangle_sandbox import Sandbox, SandboxStatus

client = Sandbox(
    api_key=os.environ["TANGLE_API_KEY"],
    base_url="https://sandbox.tangle.tools",
)

box = client.create(name="hello")
try:
    # create() returns before the sandbox runs; exec refuses until it is running.
    box.wait_for(SandboxStatus.RUNNING)
    result = box.exec("python3 -c 'print(sum(range(1_000_000)))'")
    print(result.exit_code, result.stdout)
finally:
    box.delete()
    client.close()
```

```text
0 499999500000
```

Pass `SandboxStatus.RUNNING`, not the string `"running"`: the string form raises `AttributeError` instead of `TimeoutError` when the wait times out.

</Tabs.Tab>
<Tabs.Tab>

```bash
tangle sandbox create --name hello --idle-timeout 900
tangle exec hello -- python3 -c 'print(sum(range(1_000_000)))'
```

```text
✓ Sandbox created: <sandbox id>
...
499999500000
```

`tangle sandbox create` waits up to 120 seconds for the sandbox to run, then prints its details.
`--idle-timeout 900` stops the sandbox after 15 idle minutes; a stopped sandbox keeps its files and `tangle exec` resumes it.
Put `--` before the remote command so the CLI does not read its flags. `tangle exec` exits with the remote command's exit code.

</Tabs.Tab>
</Tabs>

Neither SDK reads environment variables, so pass `baseUrl` (`base_url` in Python) every time.

## Give a coding agent a task

A new sandbox has a coding agent installed. Unless you give it your own credential, it calls models through the [Tangle Router](https://router.tangle.tools), which bills model use to your account.
`GET /v1/router-models` lists the models your key can run; [Router models](/gateway/models) describes them.

<Tabs items={["TypeScript", "Python", "CLI"]} storageKey="sandbox-lang">
<Tabs.Tab>

```ts filename="prompt.mts"
import { Sandbox } from "@tangle-network/sandbox";

const client = new Sandbox({
  apiKey: process.env.TANGLE_API_KEY!,
  baseUrl: "https://sandbox.tangle.tools",
});

const box = await client.create();
try {
  const run = await box.prompt(
    "Write fizzbuzz.py for 1 to 15, run it, and reply with its output.",
  );
  console.log(run.success ? run.response : run.error);

  const file = await box.exec("cat fizzbuzz.py");
  console.log(file.stdout);
} finally {
  await box.delete();
}
```

</Tabs.Tab>
<Tabs.Tab>

```python filename="prompt.py"
import os

from tangle_sandbox import Sandbox, SandboxStatus

client = Sandbox(
    api_key=os.environ["TANGLE_API_KEY"],
    base_url="https://sandbox.tangle.tools",
)

box = client.create(name="fizzbuzz")
try:
    box.wait_for(SandboxStatus.RUNNING)
    result = box.prompt("Write fizzbuzz.py for 1 to 15, run it, and reply with its output.")
    print(result.response if result.success else result.error)
    print(box.exec("cat fizzbuzz.py").stdout)
finally:
    box.delete()
    client.close()
```

</Tabs.Tab>
<Tabs.Tab>

```bash
tangle agent prompt --box hello --stream "Write fizzbuzz.py for 1 to 15, run it, and reply with its output."
tangle exec hello -- cat fizzbuzz.py
tangle sandbox delete hello --force
```

`--stream` prints the reply as it arrives, then the duration and token counts; without it the CLI waits and prints the whole reply.
The agent is the sandbox's default, OpenCode, on the Router's default model (`zai/glm-5.3` on 2026-11-10). `--model <id>` picks another model.
`--interactive` opens the coding agent's own terminal UI. See [Interactive mode](/sandbox/interactive).
`tangle sandbox delete` asks for confirmation unless you pass `--force`.

</Tabs.Tab>
</Tabs>

<Callout type="warning">
`prompt` does not throw when the agent fails. Check `success`, then read `response` or `error`.
A finished turn is not a finished task: check the work with a command, as the example does with `cat`.
</Callout>

## Delete what you create

`maxLifetimeSeconds` and `idleTimeoutSeconds` stop a sandbox and keep its disk. They do not delete it.
Delete in a `finally` block, as every example here does, or set `deleteAfterStoppedSeconds`. See [Create, stop and delete](/sandbox/lifecycle).

## What you did

- Created an API key and a client pointed at `https://sandbox.tangle.tools`.
- Started an isolated Linux sandbox and ran a command in it.
- Gave the sandbox's coding agent a task and checked its result.
- Deleted the sandbox so it stopped billing.
