# Examples

Complete programs you can copy and run, grouped by what they do. Each example page lists the install step, then each program with its output.
Programs that clone a repository use [tangle-network/sandbox-demo](https://github.com/tangle-network/sandbox-demo), a small Node project whose tests fail until a coding agent fixes them.

## By use case

| Page | Language | What the examples do |
| --- | --- | --- |
| [Sandboxes](/sandbox/examples/sandboxes) | TypeScript | Commands, files, lifecycle, snapshots, branches, network rules and preview links. |
| [Coding agents](/sandbox/examples/coding-agents) | TypeScript | Claude Code, Codex and OpenCode fixing tests, committing, streaming, racing and running for hours. |
| [Products](/sandbox/examples/products) | TypeScript | One sandbox per customer, chat routes, batches, hosted runs, per-turn cost and email or iMessage lines. |
| [Fleets](/sandbox/examples/fleets) | TypeScript, Python | Many agents or commands across many sandboxes under one budget. |
| [Evaluation and other clouds](/sandbox/examples/evals-and-runtime) | TypeScript, YAML | Model judges, model and coding agent comparisons, CI gates, intelligence reports, agent-runtime and agent graphs. |
| [Python](/sandbox/examples/python) | Python | The Python SDK: commands, files, snapshots, coding agents, network rules, batches and asyncio. |
| [CLI](/sandbox/examples/cli) | Shell | The tangle CLI: fix a test, pair interactively, continue a session, batches, fleets, Hub connections and JSON scripting. |

## Quickstart examples in the SDK

The TypeScript SDK ships eight short quickstart programs as data, so you can show them in your own app or tooling.
Each entry has an `id`, a `title`, a one-sentence `summary`, its `language` and the complete `code`.

```ts
import { quickstartExamples } from "@tangle-network/sandbox/examples";

for (const example of quickstartExamples) {
  console.log(example.id, "-", example.title);
}
```

```text
run-code - Run code
fix-failing-test - Fix a failing test
your-claude-subscription - Use your Claude subscription
race-two-agents - Race two agents
stream-the-work - Stream the work
lock-down-the-network - Lock down the network
share-a-preview - Share a preview
pause-and-resume - Pause and resume
```

Most of these programs, with their output, are also in [Sandboxes](/sandbox/examples/sandboxes) and [Coding agents](/sandbox/examples/coding-agents).
