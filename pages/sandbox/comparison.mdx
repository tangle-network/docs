## What Tangle Sandbox adds

- **A coding agent in every sandbox.** Prompt it with `box.prompt()` and continue the conversation with sessions. Pick Claude Code, Codex, OpenCode or another agent from `GET /v1/backends`. See [Run a coding agent](/sandbox/cloud-agents).
- **Your own Claude or ChatGPT plan.** Run Claude Code or Codex in a sandbox on the subscription you already pay for. See [Claude Code on your Claude plan](/sandbox/cloud-agents-claude-code).
- **The agent's own terminal UI.** Drive a coding agent's interactive mode inside the sandbox from your terminal or a browser. See [Interactive mode](/sandbox/interactive).
- **Fleets with a spend cap.** Run the same work across many sandboxes under one budget. See [Fleets](/sandbox/agents-fleet).
- **HIPAA placement.** `compliance: { hipaa: true }` keeps a sandbox on HIPAA-capable capacity. See [Isolation and compliance](/sandbox/security).
- **E2B-compatible REST routes.** HTTP calls that create, list, read and kill sandboxes, read and write files and run commands in E2B's REST shape work against `https://sandbox.tangle.tools/e2b`. See [Move from E2B](/sandbox/migrate-e2b).
