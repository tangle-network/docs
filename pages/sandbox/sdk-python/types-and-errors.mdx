# Types and errors

Every type here is a dataclass or enum you import from `tangle_sandbox`.
Errors are `SandboxError` with a platform `code`; [Error codes](/sandbox/errors) lists every code.

```python
from tangle_sandbox import SandboxError

try:
    box.exec("true")
except SandboxError as error:
    print(error.code, error.status, error.retryable, error.next_step)
```

## Status

`SandboxStatus` is a string enum: `PENDING`, `PROVISIONING`, `RUNNING`, `STOPPED`, `FAILED`, `EXPIRED`, `DELETED`. Values are the lowercase strings the API returns (`box.status.value == "running"`).
Pass members, not strings, to `wait_for` and `ListSandboxOptions`.

## Exported types that nothing returns

`ProvisionEvent`, `ProvisionResult`, `ProvisionStep`, `ProvisionStatus` and `BuildProgressEvent` are exported, but no method returns or yields them; Python has no provisioning progress stream.
`ImageSpec`, `ImageBuildResult` and `ImageBuildOptions` belong to the image builder, whose `build()` the service refuses. `SandboxClientConfig` holds the client's settings.

## `SandboxError`

```python
SandboxError(message, code=None, status=None, **details)
```

| Attribute | Description |
| --- | --- |
| `code` | Platform error code, such as `NOT_FOUND` or `CAPACITY_EXHAUSTED` |
| `status` | HTTP status |
| `retryable` | Whether sending the same request again can succeed |
| `next_step` | What to do about it |
| `message` | Human-readable message |
| `details` | Code-specific fields, also readable as attributes: `timeout_ms`, `current_state`, `required_state`, `quota_type`, `failures`, `fields`, `resource_type`, `resource_id`, `capability`, `current`, `limit` |
| `retry_after_ms`, `eta_seconds`, `capacity_hold` | Set when the service refuses for capacity |

Handle errors by `code`:

```python
from tangle_sandbox import SandboxError

try:
    box = client.create()
except SandboxError as error:
    if error.code == "CAPACITY_EXHAUSTED" and error.retryable:
        print("retry in", error.retry_after_ms, "ms")
    else:
        raise
```

### Aliases

Each alias is a `SandboxError` subclass for a group of codes, so `isinstance` checks work.

| Alias | Code | Raised for |
| --- | --- | --- |
| `ValidationError` | `VALIDATION_ERROR` | HTTP 400 |
| `AuthError` | `UNAUTHORIZED` | HTTP 401 |
| `NotFoundError` | `NOT_FOUND` | HTTP 404 |
| `TimeoutError` | `TIMEOUT` | HTTP 408 and client timeouts |
| `StateError` | `INVALID_STATE` | HTTP 409, and runtime calls on a sandbox that is not `RUNNING` |
| `QuotaError` | `QUOTA_EXCEEDED` | HTTP 429 and quota codes |
| `ServerError` | `INTERNAL_ERROR` | HTTP 500 and above |
| `CapabilityError` | `UNSUPPORTED` | Capability codes |
| `PartialFailureError` | `PARTIAL_FAILURE` | Partial-failure codes |
| `NetworkError` | `NETWORK_ERROR` | Connection failures and malformed stream data |
| `BatchFailedError` | `OPERATION_FAILED` | `run_batch` when the batch fails; a `ServerError` with a `cleanup` attribute |

A bad key raises a `SandboxError` with an auth code; check `code` rather than expecting `AuthError` alone.
`tangle_sandbox.TimeoutError` is not the built-in `TimeoutError`, and `except TimeoutError` with the built-in does not catch it.

### Errors raised before a request

- `Sandbox("", url)` raises `AuthError("API key is required")`.
- `Sandbox(key, "")` raises `ValidationError("Base URL is required")`.
- A runtime call on an instance whose cached status is not `RUNNING` raises `StateError`.

### Errors that are not `SandboxError`

| Call | Raises |
| --- | --- |
| `ImageBuilder.build()` | `ValueError` |
| `export_trace`, `export_trace_bundle` | `RuntimeError` when your collector answers with an error |
| `instance.intelligence()`, `fleet.intelligence()` | `RuntimeError` when there is no analysis |
| `fleet.exec()`, `fleet.prompt()` | `RuntimeError` when the one machine fails |
| `BackendConfig(type="unknown")` | `ValueError` |
| `TangleSandboxClient` streaming | `NotImplementedError` |
| `wait_for("running")` timing out | `AttributeError`; pass `SandboxStatus.RUNNING` |
